# Contributor Covenant Code of Conduct

We are committed to a welcoming and respectful open-source community. Contributors should be considerate, assume good intent while addressing harmful behavior directly, and focus discussion on ideas and evidence.

Unacceptable behavior includes harassment, discrimination, personal attacks, publishing private information, and deliberate disruption of project collaboration. Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when needed to maintain a safe environment.

Report concerns privately to the repository owner or through the GitHub security/contact mechanism configured for this repository.
