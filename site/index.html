FIRST RUN

From download to a local answer.

You do not need Git, build tools or a developer test script to use a published package. The current alpha opens the dashboard in your browser; a conventional installer and dedicated app window are planned. Settings, engines and models are stored separately from the program files.

01

Download and extract

Choose Windows, Linux or macOS above and extract the archive into a folder you own. The runtime itself is small; the engine and model are installed separately.

02

Open the app

Use the launcher included in the archive: Start-LocalAIRuntime.cmd on Windows, Start-LocalAIRuntime.sh on Linux or Start-LocalAIRuntime.command on macOS. If your older archive has no root launcher, follow its included README-INSTALL.txt.

03

Install a model and chat

In the dashboard, install the reviewed llama.cpp CPU engine and starter model. When the engine status says Ready, send a message in Chat with your model.

Updates are checked when the dashboard starts and while it remains open. Downloads are verified before install. Eligible portable Windows installs support user-confirmed apply and rollback; Linux/macOS currently require replacing the app archive after verification. The portable launchers are interim alpha tooling, not the final desktop-app experience. One-time note for v0.1.0-alpha: that first archive predates the click-to-start launcher, so install the next release manually into a new application folder once. Your settings, engines and models are stored separately and are preserved.

LOCAL BY DEFAULT

Your machine remains yours.

Local API access is unauthenticated in this alpha, so the runtime binds to loopback and should never be exposed directly to a LAN or public internet. Update checks are metadata-only; the alpha never silently replaces executables.
