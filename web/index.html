MANAGED COMPONENTS

Install an AI engine and model

Search and filter the library, review the license, then install. Engines and model weights are separate downloads and remain in your local user-data folder. Packages are verified before activation.

First test: install the llama.cpp CPU runtime and Qwen2.5 1.5B Q4_K_M model (about 1.12 GB). NVIDIA users can select a CUDA runtime when compatible. If upstream has no stable binary for your platform, the installer will clearly identify an official prerelease build.
