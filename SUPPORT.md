# Support

This project is pre-alpha. Start with the dashboard’s **Export diagnostics** control and share the report’s relevant parts after reviewing it for private details. You can send the report in this conversation or attach it to a GitHub issue; opening an issue is not required to troubleshoot. See [the diagnostics guide](docs/diagnostics.md). If the dashboard does not open, provide the OS, runtime version/commit, relevant copied console output, and the relevant `runtime.log` / `logs/<engine-id>.log` excerpt. Never post model weights, credentials, private prompts, or sensitive datasets.

Before reporting GPU support issues, include the engine release/commit, exact binary/backend, model source and format, GPU model, VRAM, driver version, and the smallest reproducible test.
