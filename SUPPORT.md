# Support

This project is pre-alpha. For bugs, provide the OS, compiler, CMake/Boost versions, sanitized configuration (remove private paths if needed), request/response, and relevant `logs/<engine-id>.log` excerpt. Never post model weights or credentials.

Before reporting GPU support issues, include the engine release/commit, exact binary/backend, model source and format, GPU model, VRAM, driver version, and the smallest reproducible test.
